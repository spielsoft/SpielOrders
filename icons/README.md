# SpielOrders — Bright Eyes

A cheerful teal squirrel offers a gold parcel. Tall tufted ears, bright oval eyes,
a small two-sided smile, periwinkle paws, and a generous cream-swept tail give the
character its personality. The parcel represents purchases kept in order.

The [rounded SVG master](spielorders-icon.svg) is the editable presentation artwork.
Use the [square SVG master](spielorders-icon-square.svg) when a platform applies
its own mask. Both use filled vector paths with no embedded bitmap, gradients,
shadows, textures, or fonts. Preserve the expression, connected tail, and visible
parcel planes when editing.

Matching PNG exports cover thumbnail through large display sizes. The macOS
package is [SpielOrders.icns](SpielOrders.icns); the Windows package is
[SpielOrders.ico](SpielOrders.ico). The iconset holds the macOS package inputs.
Rounded exports have transparent outer corners; square exports have an opaque
navy field extending to every edge.

The selected generated source and its [generation prompt](generation-prompt.txt)
are retained as provenance. The vector masters remove the source's residual
shading and define the production colors. Export future revisions from the vector
masters rather than resizing a PNG or regenerating the character.
