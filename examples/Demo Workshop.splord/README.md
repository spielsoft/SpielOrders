# Fablelight Demo Workshop

A fictional workshop for Lantern Grove, Cloud Loom, and Prism Meadow displays.

Every person, Vendor, organization, product, catalog reference, event, and supporting document in this Package is invented. Prices and contact details are demonstration data. The `.example` addresses and websites are placeholders.

## Around the workshop

Lantern Grove brings glowleaf petals and shimmer patterns together in a canopy. Cloud Loom explores imaginary cloud-thread displays. Prism Meadow arranges prismseed capsules along a miniature path.
